# توثيق الحقول والوظائف المشتركة

هذا الملف يوضح هيكلة البيانات الأساسية التي ستربط بين:
1. تطبيق المستخدم (Web - React/Vite/TypeScript)
2. لوحة الإدارة (Web - React/HTML/JS)
3. قاعدة البيانات (Convex لاحقاً)

## 1. نموذج المنتج (Product)
*   **id**: (عدد صحيح) المُعرّف الفريد للمنتج.
*   **name**: (نص) اسم المنتج بالعربية.
*   **price**: (رقم عشري) سعر المنتج.
*   **currency**: (نص) العملة (افتراضياً: د.ع).
*   **size**: (نص) حجم أو وزن المنتج (مثل: 1 كيلو، 500 غرام).
*   **imageUrl**: (نص) رابط صورة المنتج.
*   **categoryId**: (عدد صحيح) المُعرّف الخاص بالقسم الذي ينتمي إليه المنتج.

## 2. نموذج القسم (Category)
*   **id**: (عدد صحيح) المُعرّف الفريد للقسم.
*   **name**: (نص) اسم القسم (مثل: فواكه، خضروات).
*   **iconName**: (نص) اسم الأيقونة المعبرة عن القسم.

## ملاحظات التطوير المستقبلي (مع Codex)
*   عند ربط Backend مثل Convex، يجب إنشاء Schema تطابق الحقول المذكورة أعلاه.
*   تطبيق Android سيستخدم مكتبات متوافقة مع الـ Backend لاسترداد البيانات.
*   لوحة الإدارة ستقوم بإنشاء وتعديل وحذف هذه السجلات عبر نفس واجهة الـ API.
